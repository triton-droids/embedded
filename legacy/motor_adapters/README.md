# Historical ROS motor adapters

Archived SDK gateway, WebSocket demo, Torch policy bridge, protocol bindings and
associated configuration/tests. These modules are not needed by the ONNX/MuJoCo
simulation and are no longer installed by `motor_control_hybrid`.

The original standalone SDK distribution remains in
[../sdk_prototype](../sdk_prototype/README.md). Archived tests retain original
module names and require the original packaging before they can be run.
