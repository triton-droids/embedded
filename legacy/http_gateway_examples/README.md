# Historical HTTP gateway clients

`demo_main.cpp` and `demo_py.py` are clients for the former HTTP
`target_gateway_node` (`/target`, default port 8080). They are not examples of
the C++ control-core API. That gateway is not supplied by the current active
stack; the read-only motor Web monitor is not a replacement for it.

The sources are retained unchanged for reference and excluded from colcon.
Their availability does not establish a tested current robot-control path.
