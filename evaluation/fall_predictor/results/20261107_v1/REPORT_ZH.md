# 首版 IMU 跌倒预警模型训练结果

训练已完成，未接入机器人控制或 Safety 急停。

## 数据处理

- 来源：2026-11-07 夜间仿真，manifest 中 1,486 条有效轨迹。
- 排除 61 条无效轨迹、未知标签、吊架/故障窗口和包含急停状态的历史。
- 排除急停后的 14,326 个正窗口、690 个负窗口；另有 2 条轨迹没有可用窗口。
- 剩余 1,484 条轨迹、12,041 个正窗口、900,052 个负窗口。
- 按完整轨迹及模式/结果/实际扰动分层划分，避免同一轨迹的重叠窗口跨集合。

| 集合 | 轨迹 | 正窗口 | 负窗口 |
|---|---:|---:|---:|
| 训练 | 1,036 | 8,293 | 623,861 |
| 验证 | 221 | 1,770 | 133,784 |
| 测试 | 227 | 1,978 | 142,407 |

每轮训练使用全部 8,293 个正窗口，随机抽取等量负窗口，形成 1:1 的训练批次。
验证/测试保持自然分布。均值、标准差只从训练集计算。

## 训练与测试

输入为 20 帧 × 8 个 IMU 特征；网络 160→64→32→1，共 12,417 参数。
CPU 训练，Adam，学习率 0.001，batch 128。第 2 轮验证 AP 最佳，第 7 轮早停。
验证集选择达到至少 95% 正窗口召回率的最高阈值，得到 0.734506。
模型与阈值选定之后才评估测试集。

| 测试指标 | 结果 |
|---|---:|
| 正窗口召回率 | 97.17%（1,922/1,978） |
| 报警窗口精确率 | 51.76% |
| 负窗口误报率 | 1.26%（1,791/142,407） |
| PR 平均精度 AP | 0.8594 |
| ROC AUC | 0.9965 |
| 有可评估正窗口的摔倒轨迹检出 | 130/131 |
| 额外无可评估急停前正窗口的摔倒轨迹 | 20 |
| 相对确认触地的预警提前量中位数 | 295 ms |
| 相对已有 Safety 急停的提前量中位数 | 150 ms |
| 误报警起点 | 154 次 / 23.71 分钟有效负样本观察时间 |
| CPU 单窗口前向耗时中位数 / p95 | 0.762 / 1.147 ms |

提前量只对成功检出的事件计算，检出要求在触地前 300 ms 内、急停前的有效正窗口上
至少报警一次。因此 295 ms 接近评价窗口上限，不能解释成可预测更久的未来。
131 是有可评估正窗口的摔倒轨迹数，不是测试集全部 151 条摔倒轨迹。
误报警起点按相邻报警的起始沿及 1 秒冷却统计；折算约 390 次/小时，是短仿真轨迹
有效负样本观察时间上的数值，不是实机连续运行误报率。CPU 耗时不包含 ROS、缓冲
窗口构造和线程调度。

## 使用边界

该版本有提前预警能力的初步迹象，但误报仍然较多，只适合作为离线/旁路基线。
数据来自相同仿真模型、控制器和重复参考动作，尤其无扰动轨迹与运动前缀可能相似。
按轨迹划分避免了共享窗口泄漏，但不能证明新场景、动力学参数或实机泛化。
标签结果包含现有 Safety 的电机禁用响应，并不是不采取保护动作的反事实结果。

类别平衡后的 sigmoid 输出没有概率校准，不能解释为真实摔倒概率。
后续应在独立场景验证连续多帧确认/迟滞等报警策略，阈值继续只用验证集调整，
最终使用新的保留测试集评估，避免反复根据当前测试结果调参。

## 文件

- `model_torchscript.pt`：独立模型，输入 float32 `[batch,20,8]`，内含标准化，输出 logit。
- `config.json`：特征顺序、标准化、训练配置、划分数量、数据及代码哈希。
- `metrics.json`、`test_predictions.npz`：完整指标和逐窗口测试预测。
- `splits.json`：各集合的轨迹 ID。
- `history.json`：逐轮训练/验证记录。

推理时对 logit 做 sigmoid，再与上述阈值比较；第一版不自动触发急停。
